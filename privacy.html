Privacy policy

Last updated: October 24, 2026

Who uses this app

openclaw-email is a personal tool. Its only user is its developer, and it accesses one Gmail account that the developer owns. It is not offered to the public.

What it accesses

With the account owner's permission (Google OAuth scopes gmail.modify and gmail.compose), the app reads message headers and text, applies labels, moves spam out of the inbox, and creates drafts. It does not send email, and it does not permanently delete email.

Where data goes

Email is processed on the owner's own computer, including by language models that run locally. Email content is not sent to any other service, and it is not sold, shared, or used for advertising. The OAuth token is stored on that computer in a folder only the app's own user account can read.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops the app from reading or changing the account.

Contact

Questions: open an issue at github.com/kevinfox-code/openclaw-email.
